# RhythmMellow — 검증 빌드

악기를 모아 곡을 쌓고, 그 곡 위에서 보스와 합주하듯 싸우는 탑뷰 리듬 액션의 프로토타입.
맵 하나(리듬 방 셋)와 보스 하나로 한 바퀴를 돌 수 있다.

설계: `docs/superpowers/specs/2026-11-17-validation-build-design.md`
조절 기록: `docs/tuning-notes.md`

## 실행

```bash
npm install
```

```bash
npm run dev
```

브라우저(Chromium 계열)에서 표시된 주소를 열고 "시작"을 누른다. 소리는 그때부터 난다.

```bash
npm test
```

```bash
npm run build
```

```bash
npm run preview
```

```bash
npm run smoke
```

`smoke` 는 `preview` 가 떠 있는 상태에서 돌린다(약 1분 반).

## 조작

| 키 | 하는 일 |
|---|---|
| WASD / 방향키 | 이동 |
| Space | 회피. 킥·스네어 박(정박)에 맞출수록 멀리, 안전하게 |
| Q / E, 1·2·3 | 악기 전환 |
| Tab | 조절판 (모든 수치를 플레이 중에 고침, 브라우저에 저장됨) |
| ` | 디버그 표시 (박 위치, 회피 오차, 현재 악구) |
| C | 박자 맞추기 (입력 지연 보정) |

## 한 바퀴

1. 가운데 방에서 시작한다. 왼쪽·위·오른쪽에 드럼·하이햇·베이스의 방이 있다. 순서는 자유.
2. 방의 장치는 그 악기의 리듬으로 움직인다. 끝에는 회피로만 건널 수 있는 틈이 있다.
3. 악기를 얻으면 그 겹이 곡에 더해지고, 든 악기의 리듬으로 자동 공격이 나간다.
4. 셋을 다 모으면 아래쪽 문이 열린다. 보스는 이 곡의 주선율이다.
5. 보스전은 네 마당(기·승·전·결)이다. 악구의 조건을 못 채우면 같은 악구가 변주되어 다시 돈다.

## 개발용 주소 옵션

- `?seed=12` 다른 곡
- `?skip=boss` 악기 셋을 들고 보스 문 앞에서 시작
- `?god=1` 맞지 않음
- `?debug=1` 디버그 표시를 켠 채 시작
- `?jam=1` 게임 없이 겹을 켜고 끄며 듣기

## 구조

- `src/core` — 박자, 곡 생성, 판정, 게임 규칙. 브라우저에 기대지 않는 순수 로직이며 테스트 대상이다. 고닷으로 옮길 때 가져갈 부분.
- `src/audio` — Web Audio 신디와 예약 재생.
- `src/render`, `src/input`, `src/ui` — 화면, 키, 조절판. 전부 임시.
