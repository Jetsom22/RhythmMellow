# 비주얼 레퍼런스

기획자가 대화에서 준 참고 이미지. 저작권은 각 원작자에게 있고, 방향을 맞추는 참고로만 쓴다(게임에 넣거나 따라 그리지 않는다).
파일은 Git LFS에 있다. 안 보이면 `git lfs pull` 을 한다.

기획자의 말: **"Geometric Abstract, Minimalism UI, Abstract Vector Art 계열"**. 그 전에 든 참고작은 미니 메트로와 글리피카(Glyphica: Typing Survival)다.

## 첫 묶음 (시안 2를 본 뒤. "아예 시안을 다시 뽑아야 한다는 게 뭔지 알 거야")

| 파일 | 무엇 |
|---|---|
| `a1-shapes-vermilion.png` | 밝은 회색 바탕에 주홍과 숯색. 굵은 면, 해칭, 점 격자, 물결선이 겹친 도형 모음 |
| `a2-lines-black.png` | 크림 바탕에 검정만. 가는 평행선 다발, 동심선, 굵은 원반의 대비 |
| `a3-posters-ochre.png` | 황토와 검정의 포스터 넷. 동심 호, 겹친 사각 틀, 글자 배치 |
| `a4-poster-navy-arcs.webp` | 남색 바탕에 주황·빨강·파랑의 굵은 동심 호 |
| `a5-teal-magenta-yellow.webp` | 청록 바탕에 마젠타 선 다발과 노란 원반, 흰 동심 호 |

## 둘째 묶음 (추가 레퍼런스. 이때 "CMY는 버려도 돼")

| 파일 | 무엇 |
|---|---|
| `b1-organic-blobs.webp` | **유기적인 곡선 덩어리.** 크림 바탕에 녹슨 붉은색, 짙은 붉은색, 숯색, 회색, 살구색의 물렁한 덩어리가 겹쳐 흐르고 원이 떠 있다. 다른 넷과 달리 기하 도형이 아니다. 시안에서는 아직 쓰지 않았다 |
| `b2-midcentury-gradient.png` | 미드센추리풍. 면 안에 얕은 그라데이션, 큰 원, 가는 세로선 둘 |
| `b3-tile-ochre-black.png` | 검정·황토·크림의 기하 타일 무늬 |
| `b4-arch-lines-navy.png` | 남색 바탕에 주황 원반과 파란 동심 아치 선 |
| `b5-arch-lines-rust.png` | 크림 바탕에 회색 동심 아치 선, 녹슨 반원의 띠, 검은 잎 |

## 여기서 시안으로 옮겨진 것

- 굵은 원반과 가는 선의 대비, 동심 아치, 화면을 가르는 가는 세로선 둘, 면 안의 얕은 그라데이션 → 시안 3
- 팔레트 넷(rust, mid, navy, ochre)의 색은 이 이미지들에서 왔다
- `b1` 의 곡선 덩어리는 옮기지 않았다. 쓸지는 정해지지 않았다
